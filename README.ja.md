# ski-jump-pose-local

[English](README.md) | 日本語

スキージャンプの踏切を分析する**ローカル PC 用**のツールです。
動画を登録すると、PC 上で YOLOv8-Pose が骨格を検出します（Mac では GPU 相当の MPS を使います）。
結果はブラウザで、映像に骨格を重ねて見られます。**過去の試技と 2 本並べて、踏切で揃えて比較**することもできます。

- クラウド（AWS）は使いません。利用料はかかりません。
- **一度推論した動画は再推論しません。** 同じ動画を同じ範囲で登録し直すと、保存済みの結果をすぐに使います。

## 必要なもの

| もの | 確認したバージョン |
|---|---|
| Python | 3.10 |
| ffmpeg / ffprobe | `brew install ffmpeg` |
| Node.js ＋ pnpm | Node 22 / pnpm 10（画面のビルドに使う） |

```bash
# Python の依存（初回のみ。torch も入るので数分かかる）
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

`yolov8m-pose.pt` が無い場合は、初回の推論時に自動でダウンロードされます。

## 起動

```bash
./scripts/start.sh
# → http://127.0.0.1:8000/ をブラウザで開く
```

画面のソースを変えたときだけ、自動でビルドし直します。
サーバは `127.0.0.1` でしか待ち受けません（他の PC からは見えません）。

開発時は、次の 2 つを別々のターミナルで起動します。Vite が `/api` を 8000 番へ転送します。
```bash
python3 server/app.py
cd frontend && pnpm dev
# → http://localhost:3200/
```

## 使い方

1. **登録**：動画ファイルを「動画を登録」の枠へドラッグ＆ドロップするか、選択します。複数の動画をまとめて落とすこともできます。
   必要なら開始・終了の秒を入れて「登録して解析」を押します（複数の場合は全部に同じ範囲を使います）。
   踏切の前後だけに絞ると早く終わります。
2. **開く**：解析が終わったら「開く」を押します。最初に「台の設定」を入れます。
   - 台の角度（度）：進行方向に向かって上りが＋、下りが−です。
   - 台の先端：映像上でクリックして指定します。
   - 腕の角度の基準：平地か斜面かを選びます。判定に使う角度も入れられます。
   - 映像の横幅（m）：入れると、速度を m/s で表示します。

   桃色の線が台面、緑の点線が腕の基準として映像に重なります。
   台の設定は保存され、**次に開く動画の既定値**にもなります（カメラを固定している前提です）。
3. **比較**：一覧で 2 本にチェックを入れて「2 本を比較」を押します。
   踏切の時刻で自動的に揃います。ずれていれば「B を 1 コマ前へ／後へ」で補正します。

キー操作：`Space` 再生／停止、`←` `→` 1 秒（`Shift` を押すと 10 秒）、`,` `.` コマ送り

## 表示する指標

詳しい定義は [docs/metrics.md](docs/metrics.md) にあります。

| 指標 | 内容 |
|---|---|
| 膝角度 | 腰・膝・足首の 3 点で測る角度（膝裏の角度）。**左右のうち信頼度の高い脚 1 本**で計算します |
| すね−台面 | 足首→膝のベクトルと台面がなす角度。90° で台に垂直、小さいほど前傾です |
| 腕の高さ | 肩→手首が基準線（平地または斜面）から何度上がっているか。判定角度を入れると、超えたかどうかも表示します |
| 足首の速度 | 画面幅比（%/s）。映像の横幅を入れると m/s で表示します |
| 角速度（rad/s） | 膝を中心に、腰・足首・肩・手首がどれだけ速く回っているか。膝関節が伸びる速さも出します |
| 踏切 | 足首が台の先端を越えた瞬間（フレームの間は補間します）。手動でも指定できます |
| 伸び切り | 踏切の前後 0.5 秒で膝角度が最大になった瞬間。踏切より「○秒 早い／遅い」で表示します |

## 処理時間の目安

Apple M2 で 1920x1080・23.98fps の動画を解析した実測値です。**約 20 フレーム/秒**で、15 秒の動画が約 20 秒で終わります。
